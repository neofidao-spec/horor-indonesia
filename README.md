# Malam Jumat Kliwon

Horor interaktif 2D — WebView Android APK.

> *"Mbah pergi. Desa sepi. Dan sesuatu menunggu di kegelapan."*

## Babak
1. **Rumah Tua** — Cari jalan keluar, pecahkan puzzle, hindari jumpscare
2. **Makam** — Cari makam Mbah, hindari Genderuwo
3. **Sawah** — Kumpulkan pancang bambu, ritual, hadapi Kuntilanak

## Kontrol
| Keyboard | Touch | Aksi |
|----------|-------|------|
| WASD / Arrow | D-pad bawah kiri | Gerak |
| Spasi / Enter / E | Tombol AKSI kanan bawah | Interaksi |
| P / Esc | Tombol pause atas kanan | Jeda |
| S | — | Simpan |
| R | — | Ritual (scene 3) |

## Build APK
Push ke GitHub → otomatis build via Actions.
Atau local:
```bash
cd android
./gradlew assembleRelease
```
